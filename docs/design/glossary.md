# Glossário (vôlei → código)

Fonte única de nomes. Antes de usar um termo de vôlei no código, ele precisa estar aqui. Termo novo: adicionar na tabela certa.

## Técnicas (`Technique`)

Como o atleta toca na bola.

| Português | Código |
|---|---|
| Manchete | `bump` |
| Toque (para frente) | `overhead` |
| Toque de costas | `back-overhead` |
| Cortada | `spike` |
| Largada | `tip` |
| Caixinha | `roll-shot` |
| Peixinho | `dive` |
| Saque flutuante | `float-serve` |
| Saque viagem | `jump-serve` |

## Ações (`Action`)

| Português | Código |
